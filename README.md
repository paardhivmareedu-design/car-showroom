# ⚡ VORTEX MOTORS – Luxury & High-Performance Car Showroom

**BEYOND POWER. PURE VELOCITY.**

VORTEX MOTORS is a premium automotive showroom website designed to showcase luxury hypercars, high-performance vehicles, and next-generation electric grand tourers.

The website delivers a modern luxury experience with elegant layouts, detailed vehicle specifications, advanced features, model comparisons, customer reviews, and VIP test-drive booking.

🌐 **Live Demo:** https://superb-moonbeam-7e9f0d.netlify.app/

---

## ✨ Features

- **Premium Homepage:** Luxury automotive-themed landing page.
- **Vehicle Collection:** Explore six exclusive high-performance vehicles.
- **Vehicle Categories:** Browse hypercars, electric vehicles, executive sedans, and performance SUVs.
- **Technical Specifications:** Detailed information about engines, horsepower, acceleration, speed, and technology.
- **Advanced Features:** Explore automotive engineering, electrification, aerodynamics, and luxury craftsmanship.
- **Model Comparison:** Compare vehicle specifications side by side.
- **Customer Reviews:** Dedicated section showcasing automotive reviews and testimonials.
- **VIP Test Drive Booking:** Form to request a private test-drive appointment.
- **Responsive Interface:** Designed for different screen sizes.
- **Modern UI/UX:** Elegant typography, premium visuals, and professional layouts.

To run this project locally:

**1. Clone the repository**

```bash

```

**2. Open the project folder**

```bash

```

**3. Open the website**

Open `index.html` in your browser.
